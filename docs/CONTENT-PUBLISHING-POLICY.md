# Content publishing policy

Before a record becomes public, the owner should confirm:

- This record contains no passwords, API keys or private tokens.
- It contains no private address or sensitive personal document.
- It contains no confidential employer/partner information.
- It contains no proprietary research detail intended to remain restricted.
- Research status is represented honestly (idea, in progress, preprint, submitted, under review, published).
- Measured results are real and reproducible from the recorded experiment where applicable.
- IP-sensitive material has been considered before disclosure.

For permission-required ideas, publish only the deliberately selected disclosure level. Detailed technical material should remain private or be shared only after an appropriate agreement and owner-approved permission.
